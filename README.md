# Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website designed to showcase my skills, projects, experience, and journey as a software engineer.

Built with **HTML5, CSS3, and JavaScript**, the portfolio features a clean user interface, smooth animations, and responsive layouts to provide an engaging experience across different devices.

## Live Demo

**Website:** [View My Portfolio](https://my-portfolio-beta-ruddy-17.vercel.app/)

---

## Overview

This portfolio serves as a central place to explore my development work, technical skills, and projects.

It focuses on presenting information through a modern design, intuitive navigation, and subtle animations while maintaining usability and accessibility.

## Features

- **Modern UI/UX:** Clean design with dark theme, glassmorphism effects, and modern visual elements.
- **Smooth Animations:** GSAP-powered transitions, scroll-triggered animations, and interactive elements.
- **Responsive Design:** Optimized layouts for desktop, tablet, and mobile devices.
- **Project Showcase:** Dedicated sections for presenting projects, technologies, and development experience.
- **Interactive Elements:** Custom cursor effects and engaging hover interactions.
- **Contact & Social Links:** Easy access to professional profiles and contact information.
- **Lightweight Architecture:** Built with standard web technologies without requiring a complex build process.

## Getting Started

Follow these steps to run the portfolio locally.

### Prerequisites

- Git
- A modern web browser
- VS Code or another code editor

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd YOUR_PROJECT_FOLDER
```

### 3. Run Locally

Open `index.html` in your browser.

Alternatively, use the Live Server extension in VS Code for a better development experience.

---

## Customization

The portfolio can be customized by modifying the following files:

| File | Description |
|---|---|
| `index.html` | Update personal information, projects, and content |
| `style.css` | Customize colors, typography, layouts, and responsive styles |
| `script.js` | Modify interactive functionality and animations |

### Personal Information
Update your name, introduction, skills, experience, and social media links.

### Projects
Add your projects with descriptions, technology stacks, screenshots, and GitHub or live demo links.

### Design and Theme
Customize CSS variables, colors, typography, animations, and layout styles to match your preferred visual identity.

## Deployment

The portfolio is deployed using **Vercel**.

To deploy your own version:

1. Push your project to GitHub.
2. Connect the repository to Vercel.
3. Configure the deployment settings.
4. Deploy your website.
